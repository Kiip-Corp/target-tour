정부 과제
각종 관광 홍보 리소스 및 채널 보유에도 불구하고, 다채널 배포 과정의 파편화로 인한 번거로움 발생 및 마케팅 캠페인 실행력 저하

목적
한국에 방문하는 외국인 대상으로 타깃 마케팅을 잘 할 수 있을까

기능1
1. 분석 — 지역 × 국적별 관광 수요·시장·소비 데이터를 시각화


기능2
2. 추천 — 데이터 종합해 "이 지역 × 이 국적 × 이 시점"이 최적 타깃이라고 스코어로 추천 (소구점 정의)


기능3
3. 생성 — 그 타깃용 채널별 홍보 카피를 현지어로 자동 생성

추가기능1
- 관광공사 공개 데이터로 우리 고객이 몰려 있는 동네를 찾는 사내 툴
- 오프라인 제휴처를 감으로 정하던 걸 근거 있게 정하기 위함. 
- 지도에 원으로 지역을 찍는데, 핵심은 원 크기(규모)가 아니라 색(집중도)
- 중요데이터: '전체 외국인 대비 우리 타깃이 유독 몰린 곳'
- 방문자 수 순위는 이미 아는 답이라 볼 필요가 없음

추가기능2
- 기간 별로 외국인 밀집도 찾기


데이터 연동1
관광 수요강도 지수 · 관광 다양성 지수 → 한국관광 데이터랩 (data.go.kr)

데이터 연동2
방한 외래관광객(국적·월·연령) · 외국인 소비액 → 한국관광 데이터랩

이하 원문

## 목표 (핵심 흐름 3단계)

1. 분석 — 지역 × 국적별 관광 수요·시장·소비 데이터를 시각화
2. 추천 — 데이터 종합해 "이 지역 × 이 국적 × 이 시점"이 최적 타깃이라고 스코어로 추천 (소구점 정의)
3. 생성 — 그 타깃용 채널별 홍보 카피를 현지어로 자동 생성


## 리액트 데모
- 위 3단계가 실제로 다 작동하는 상태. 콘텐츠 생성은 진짜로 Claude API 호출해서 돌아감 (라이브 데모 포인트)
- 데이터는 전부 목업 — fetchDemandMatrix() 함수와 NATION_DATA 객체 딱 두 군데에 몰아넣어놨음. 여기만 실제 API로 갈아끼우면 됨
- 프론트 대시보드(히트 매트릭스, 시장 스냅샷, 방문량×소비액 사분면, 검색 키워드 후크, 추천 카드)는 다 짜여 있음
